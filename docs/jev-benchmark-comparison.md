在 200 个业务案例、每家重复 5 轮（各 1,000 次、合计 2,000 次真实判断）的实验中，DeepSeek Flash 与官方 Jev 的最终准确率分别为 **91.80% 和 82.50%**，按实测 token 用量及官方价目表核算的每 1,000 次 API 成本分别约为 **$0.11946 和 $0.04698**（美元，未与后台账单对账）。

## 怎么理解这次比较

官方 Jev 同题配对的中位加速约 **3.36 倍**，API 成本约低 **60.7%**，但当前插件配置会让更多合法操作转为人工确认。默认继续使用 Harness 原有模型，Jev 作为可配置选项。

这张表统计最终适配器决策：Jev 使用固定的 **0.90 放行概率阈值**，其原始 Choice 离线准确率为 90.30%，不能直接等同于最终放行表现，也不能据此推荐取消阈值。两家使用相同基础授权规则，但接口格式、输出方式与后处理不同。

两家都不是读取 Agent 完整历史：生产插件提取最近最多 4 条直接用户消息、合计最多 4,000 个字符，并附上本次工具操作信息。benchmark 使用人工构造的对应授权上下文，直接调用真实分类器；它不是让两个 Agent 分别连续完成 200 个完整任务。19 个案例使用抽象选择工具；只看 181 个实际 Shell 案例时，两家准确率分别为 97.13% 和 80.66%。

五轮重复不等于五套独立数据，结果不代表生产错误率。隐藏脚本正文对两家都不可见，DeepSeek 的 4 次响应错误也不能算作识别出危险。另有 400 次执行／阻止对照和两组真实 Harness 功能验收，不计入上述 2,000 次判断。

## 成本怎么算

依据 2026-09-26 正式实验保存的 API usage，剔除预热，保留返回 usage 的失败请求；每家均有 1,000 条用量记录。以下采用当次核对的官方美元价目表，不含赠金、税费、额外验收、Docker 资源与人工确认成本，也不是后台实扣账单。

- DeepSeek：未缓存输入 226,395 tokens、缓存输入 531,625 tokens、输出 139,843 tokens；推理 tokens 已包含在输出中。实验在周六，按低峰价计算：`(226395 × 0.15 + 531625 × 0.003 + 139843 × 0.60) / 1000000 = $0.119459925`。[官方价格与低峰规则](https://api-docs.deepseek.com/quick_start/pricing/)
- Jev：输入 1,118,625 tokens，输出免费：`1118625 × 0.042 / 1000000 = $0.04698225`。[官方价格](https://docs.typesafe.ai/models)

两家的 tokenizer 和请求格式不同，因此同样的判断材料不意味着 token 数相同。100 万次成本只是保持本轮输入长度、输出长度和缓存比例的线性推算；DeepSeek 高峰价格不同，不能直接套用本表。
